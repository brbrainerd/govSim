<objective>
Make the engine charge clout from the player's raw choices (budget plus deals), using the same pure function the UI calls for its preview, so the preview and the result can never disagree and a hand-edited decision cannot mint clout.

Purpose: FND-05. Phase 2 saves are input logs of these Decisions, so the engine must validate them rather than trust UI-computed numbers. Per A8, deals made without calling the vote are voted and charged at Next turn.
Output: decisions.ts with resolveBill, a bill-driven game.ts step with a report.log, a Session that previews with resolveBill, a 2-line Congress change, and tests (grid, edges, tampering, Session preview).
</objective>
