<title>Implement Native Deflate-Raw Run Compression and Decoding</title>
<read_first>
- src/app/save.ts
</read_first>
<action>
1. Create `src/app/share.ts`:
   - Implement `encodeRunCode(run: { seed: number; options: { party: string }; inputs: any[] }): Promise<string>`:
     - Serialize minimal run descriptor: `{ s: run.seed, p: run.options.party, i: run.inputs }`.
     - Compress using `new CompressionStream('deflate-raw')`.
     - Encode compressed bytes to URL-safe base64 (`base64url`).
   - Implement `decodeRunCode(code: string): Promise<{ seed: number; party: 'D' | 'R'; inputs: any[] } | null>`:
     - Decode `base64url` into bytes.
     - Decompress using `new DecompressionStream('deflate-raw')` with strict byte length limit (e.g., max 64 KB uncompressed, GR-34).
     - Validate decoded payload structure and types; return `null` on corrupt or invalid payloads.
   - Implement `createShareUrl(run: { seed: number; options: { party: string }; inputs: any[] }): Promise<string>`:
     - Returns `${window.location.origin}${window.location.pathname}#run=${code}`.
2. Create `src/app/share.test.ts`:
   - Test round-trip: encode game run -> decode run code -> verify identical seed, party, and decisions.
   - Test corruption resilience: tampered bytes, truncated base64, oversized inputs all return `null` cleanly without crashing.
</action>
