<action>
1. In `src/engine/amendments.ts`:
   - Implement `checkAmendmentCongressionalProposal(amendmentId, houseVotes, senateVotes)`:
     - Requires `houseVotes >= 290` AND `senateVotes >= 67`.
   - Define `ActiveAmendment` state:
     - `id`: AmendmentId
     - `proposedTurn`: number
     - `ratifiedStates`: readonly string[] (state codes that have ratified)
     - `isRatified`: boolean
     - `isExpired`: boolean
   - Implement pure `tickAmendmentRatification(active: ActiveAmendment, state: GameState, side: 'D' | 'R'): ActiveAmendment`:
     - Evaluates state alignment relative to player `side` ('aligned', 'divided', 'opposed') using `getStateLegislature`.
     - Advances ratification progress turn by turn drawing strictly from the isolated `'reform'` stream.
     - Aligned legislatures ratify rapidly (1-2 turns).
     - Divided legislatures ratify if approval >= 55% or presidential clout campaigned.
     - Opposition legislatures ratify only if approval >= 65% and high public momentum.
     - If `ratifiedStates.length >= 38`, marks `isRatified = true`.
     - If `state.turn - active.proposedTurn >= 28`, marks `isExpired = true`.
     - Strictly enforce party blindness: do not use the word `party` or `parties` in engine code or comments.
2. Integrate into `src/engine/game.ts`:
   - Add `activeAmendment?: ActiveAmendment` and `ratifiedAmendments: readonly AmendmentId[]` to `GameState`.
   - In `step()`, call `tickAmendmentRatification` each turn if an amendment is active.
   - When an amendment is ratified, apply its permanent constitutional benefits to `GameState` and log event in Turn Report.
