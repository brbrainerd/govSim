<action>
1. In `index.html` and `vite.config.ts`:
   - Keep `"connect-src 'self' https://*.r2.cloudflarestorage.com"` as the exact prefix (so `src/testing/telemetry.test.ts` line 114 `.toContain("connect-src 'self' https://*.r2.cloudflarestorage.com")` passes untouched) and append `https://openrouter.ai https://generativelanguage.googleapis.com https://api.groq.com http://localhost:* http://127.0.0.1:*` before the semicolon.
2. Create `src/app/ai-providers.ts` with:
   - `AiProviderId`: `'off' | 'openrouter_free' | 'browser_ai' | 'gemini_free' | 'groq_free' | 'custom_openai'`.
   - `AiConfig`: `{ provider: AiProviderId; apiKey: string; model: string; customEndpoint: string; freeModelFallbacks: string[] }`.
   - `DEFAULT_OPENROUTER_FREE_MODELS`: `['openrouter/free', 'meta-llama/llama-3.3-70b-instruct:free', 'google/gemma-3-27b-it:free', 'qwen/qwen3-32b:free', 'deepseek/deepseek-chat-v3-0324:free']`.
   - `discoverOpenRouterFreeModels(fetchImpl = fetch): Promise<string[]>`: fetches `https://openrouter.ai/api/v1/models`, filters models where `id.endsWith(':free')` or (`pricing?.prompt === '0' && pricing?.completion === '0'`), prepends `'openrouter/free'`, and returns the deduplicated list.
   - `generateAiCompletion(systemPrompt: string, userPrompt: string, config = loadAiConfig(), fetchImpl = fetch): Promise<string | null>`:
     - If `config.provider === 'off'`, immediately returns `null` with ZERO network requests.
     - For `'openrouter_free'`: tries `[config.model, ...config.freeModelFallbacks]` against `https://openrouter.ai/api/v1/chat/completions`; if a model returns `429` or `5xx`, automatically retries the next `:free` model in the cascade!
     - For `'browser_ai'`: detects `(globalThis as any).ai?.languageModel ?? (globalThis as any).LanguageModel` and runs local prompt completion.
     - For `'gemini_free'`: calls `https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent?key=${config.apiKey}`.
     - For `'groq_free'`: calls `https://api.groq.com/openai/v1/chat/completions`.
     - For `'custom_openai'`: calls `${config.customEndpoint}/chat/completions`.
   - OpenRouter OAuth PKCE helpers (`startOpenRouterPkceAuth`, `completeOpenRouterPkceAuth`) using Web Crypto SHA-256 `code_challenge`.
3. Create `src/app/ai-providers.test.ts` testing:
   - `discoverOpenRouterFreeModels` filters `:free` and `0`-cost models from mocked `/api/v1/models` response.
   - `generateAiCompletion` cascades to the next `:free` model when the primary model returns HTTP `429`.
   - `generateAiCompletion` makes zero network calls when `provider === 'off'`.
</action>
