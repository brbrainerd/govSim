2. In `src/engine/game.ts`:
   - In `GameState`:
     - Add `geopoliticalSchedule: readonly [number, string][]` or serialize `Map<number, string>`.
     - Add `activeGeopoliticalCrises: readonly ActiveCrisis[]`.
     - Add `resolvedGeopoliticalCrises: readonly string[]`.
   - In `initGame(seed, options)`:
     - Initialize `geopoliticalSchedule` via `getGeopoliticalSchedule(seed)`.
     - Initialize `activeGeopoliticalCrises: []`.
   - In `stepGame(state, decisions)`:
     - 1. Advance existing active geopolitical crises countdowns.
     - 2. If decisions contain a resolution for an active geopolitical crisis:
          - Apply option clout cost and immediate effects.
          - If option has `scheduledKind` or multi-quarter impact, register scheduled modifier in `state.scheduledModifiers`.
          - Mark crisis as resolved and remove from active list.
     - 3. Check for expired countdowns:
          - If any active crisis has `turnsRemaining <= 0` and is unaddressed:
            - Apply automatic severe escalation penalties (inflation shock, approval drag, emergency expenditure).
            - Record escalation in `state.lastReport.events` / causal trace.
            - Remove from active list.
     - 4. Check schedule for new geopolitical crisis arriving at current turn:
          - If scheduled, add to `activeGeopoliticalCrises` with `turnsRemaining: 2`.
          - For Autopilot mode (`options.autopilot === true`):
            - Automatically resolve immediately using the designated `option.autopilot === true` option (`CRISIS-03`).
