   - Extend `ActiveCrisis`:
     ```ts
     export interface ActiveCrisis {
       // ... existing fields
       readonly isGeopolitical?: boolean;
       readonly turnsRemaining?: number;
       readonly startTurn?: number;
       readonly deadlineTurn?: number;
     }
     ```
   - Implement `getGeopoliticalSchedule(seed: number): Map<number, string>`:
     - Pre-schedules turns for geopolitical crises using `draw(seed, 'geopolitics', 0, ...)` and `draw(seed, 'geopolitics', turn, ...)`.
     - Ensures 1–2 events per 4-year term (turns 1–16) spaced at least 3 turns apart from each other and avoid turn 1 (honeymoon).

     - Tracks active geopolitical crises spanning up to 2 quarters if unaddressed (`turnsRemaining = deadlineTurn - turn`).
   - Implement `checkGeopoliticalEscalation(activeCrisis: ActiveCrisis, currentTurn: number): boolean`:
     - Detects when `currentTurn > activeCrisis.deadlineTurn` without resolution, triggering the escalation shock.
2. In `src/engine/deadlines.ts`:
   - Add support in `getImminentDeadlines` or a companion helper for `DeadlineStatus` of type `'geopolitical_crisis'` with critical status when `turnsRemaining <= 1`.
