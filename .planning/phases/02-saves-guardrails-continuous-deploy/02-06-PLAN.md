3. Create `.dockerignore` excluding `node_modules`, `.git`, `.planning`, tests, coverage.
</action>

   - Trigger on push to `master` (concurrency group `deploy`).
   - Set up Docker Buildx.

   - Trigger Coolify promotion via `node scripts/ci/promote.ts`.
   - Run `node scripts/ci/verify.ts` against target deployment URL.
