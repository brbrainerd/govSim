<task_name>Implement save serializer, replay validator and trust boundary (src/app/save.ts)</task_name>
<read_first>
- src/engine/hash.ts
- src/engine/game.ts
- src/engine/decisions.ts
</read_first>
<action>
Create `src/app/save.ts` with:
1. `SaveFile` interface matching schema: `{ format: 'govsim', v: 1, engine: '0.2', seed: number, start: BaselineYearData, options: GameOptions, inputs: Decisions[], check: string }`.
2. `serializeSave(session: Session): string`: produces formatted JSON including Murmur3 `check` of end state.
3. `parseSave(json: string): SaveFile`: strict validator checking:
   - string length <= 1,000,000 chars.
   - valid JSON parse.
   - exact format 'govsim', v: 1, engine: '0.2'.
   - finite integer seed.
   - valid start baseline data.
   - valid options (party 'D' | 'R').
   - inputs array where each Decisions passes `validateDecisions` (no illegal levers, no negative/infinite values, no unknown deal IDs).
   - replaying the input log produces a state whose `stableHash` matches `check`.
4. `storeAutosave(session: Session)` and `loadAutosave()` using `localStorage['govsim_autosave']`.
5. Call `navigator.storage?.persist?.()` where available (GR-34).
</action>

</verify>
<acceptance_criteria>
- `parseSave` throws on corrupted or tampered inputs and succeeds on valid inputs.
- Replayed state matches live state bit-for-bit.
</acceptance_criteria>
</task>
