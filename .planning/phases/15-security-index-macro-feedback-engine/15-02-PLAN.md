# Plan 15-02: Macro Feedback Engine & Phillips Curve Integration (SEC-03)

## Objective
Implement pure macroeconomic feedback loops where active geopolitical supply disruptions feed into energy/import deflators and output gap drag via registered coefficients (`geopoliticalEnergyInflation`, `geopoliticalShippingInflation`, `geopoliticalSupplyOutputDrag`).

## Proposed Changes
1. **Trace Source Registration (`src/engine/trace.ts` & `src/content/text/why.ts`)**:
   - Register `'geopolitical:'` in `SOURCE_PREFIXES` in `src/engine/trace.ts`.
   - Add plain-language translations in `WHY_COPY` in `src/content/text/why.ts`:
     - `'geopolitical:energy'`: `'Global energy supply disruption'`
     - `'geopolitical:shipping'`: `'Maritime trade route bottleneck'`
     - `'geopolitical:supply'`: `'International supply chain drag'`
2. **Engine Macro Feedback Integration (`src/engine/game.ts`)**:
   - In `step()`, inspect `activeGeoCrises`:
     - For active `oil_embargo`: inject `C.geopoliticalEnergyInflation` into inflation ledger (`inf.add('geopolitical:energy', ...)`), and `-C.geopoliticalSupplyOutputDrag` into output gap ledger (`g.add('geopolitical:supply', ...)`).
     - For active `shipping_blockade`: inject `C.geopoliticalShippingInflation` into inflation ledger (`inf.add('geopolitical:shipping', ...)`), and `-C.geopoliticalSupplyOutputDrag` into output gap ledger.
     - For active `debt_contagion`: inject `-C.debtContagionGdpHit` into output gap ledger.
3. **Verification**:
   - Ensure `isKnownSource()` validates all added terms.
   - Run invariants property test (`src/engine/invariants.property.test.ts`) across 1000 randomized games to verify conservation, bounds, and determinism.
   - Update golden replay fixtures if geopolitical crises are active during golden seeds.
