<action>
Create `src/engine/director.ts`:
- Export `scheduleTurnEvents(seed: number, turn: number, state: GameState): ActiveCrisis | null`.
- Uses keyed draws `uniform(seed, 'crisis', turn, 'event_roll')`.
- Enforces pacing rules (GR-08):
  - Return null if `turn <= 2`.
  - First crisis guaranteed on turn 3, 4, or 5.
  - Cooldown: checks if previous turn or 2 turns ago had a crisis.
  - For exogenous events: pure function of `(seed, turn)`.
  - For endogenous events: evaluates condition on `state.econ` (`debt/gdp > 1.25`, `gini > 0.495`, etc.).
Update `src/engine/game.ts`:
- In `GameState`: add `readonly activeCrisis: ActiveCrisis | null`.
- In `newGame()`: initialize `activeCrisis = null`.
- In `step()`: invoke `scheduleTurnEvents` to populate `next.activeCrisis`.
</action>
