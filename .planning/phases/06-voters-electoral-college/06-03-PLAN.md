<task_name>1. Implement Voters.svelte screen with 270 bar, state drawer, and sortable table fallback</task_name>
<description>
Create `src/screens/Voters.svelte`:
- Implement the 4-part layout grammar using `ScreenLayout.svelte`:
  - **Question**: `"Who supports you?"`
  - **Main Area**:
    - Header with View Mode segmented toggle (`[Map View]` / `[Table View]`).
    - When Map View: renders `USMap.svelte` with selected state highlighting.
    - When Table View: renders fully accessible semantic `<table>` with sortable columns: State, EV, Support %, 2024 Margin, Current Margin, Outlook. Clicking column headers toggles ascending/descending order (`VOT-01`).
    - **Electoral College 270 Bar**:
      - Displays `"You <playerVotes>"` (navy/sky) vs `"Them <opponentVotes>"` (alert/brick).
      - Prominent `(270)` indicator peg with vertical tick line.
      - Segments showing Safe, Likely, Lean, Tossup, Lean, Likely, Safe.
      - In Year 3+ (turn $\ge 9$), renders honest projection whiskers/range (`<low> – <high> EV`) (`VOT-03`).
  - **Learn Strip**:
    - `[Learn]` badge + civics link/button `"Myth? How the Electoral College works →"`.
  - **Sidebar (Next Step)**:
    - Selected state inspector card:
      - State name, electoral vote count, star badge if tipping-point or swing state.
      - Support %, arrow indicator, and change from baseline.
      - Sourced causal reasons (e.g., `Farmers upset by tariffs`, `Strong manufacturing output`, `National approval shift`) (`VOT-02`).
    - Action cards:
      - `"Give a speech in <State>"` (opens Speech modal if unlocked).
      - `"Visit swing states"`.
    - Primary Stamp Button (bottom-right): contextual action linking to Budget or Powers.
</description>
