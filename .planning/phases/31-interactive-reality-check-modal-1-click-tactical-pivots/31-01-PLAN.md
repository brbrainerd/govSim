       - Display the result feedback banner (Correct / Misconception) with `myth.predictionPrompt.refutation`.
       - Render the `MYTH BUSTED` stamp in the myth column with `.slam` animation class when `stampSlam` is true.
       - Render flowchart and character scene.
       - Render `.levers-list` with interactive `<button class="lever-pivot-btn" data-testid="lever-pivot-btn" onclick={() => onPivot?.(action)}>` buttons showing `⚡ {action.label} →` and title tooltip `action.hint`.
