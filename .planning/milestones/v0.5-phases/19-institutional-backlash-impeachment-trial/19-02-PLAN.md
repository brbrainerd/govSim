# Plan 19-02: House Impeachment Vote & Senate Conviction Trial Mechanics (IMPEACH-02, IMPEACH-03)

## Objective
Implement pure deterministic civic voting calculations for the 435-seat House impeachment vote when Heat exceeds 80, and the subsequent 100-seat Senate trial requiring a 2/3 supermajority (67 votes) to convict, terminate the term, and forfeit the offshore stash.

## Scope
1. **House Impeachment Model (`src/engine/evil.ts`)**:
   - `calculateHouseImpeachmentVote(seatDelta: number, heat: number, approval: number, party: 'D' | 'R')`:
     - Opposition party base votes (e.g. 213 + opposition seat delta).
     - Presidential party defection votes driven by `(heat - 80)` severity and low public approval (<45%).
     - Clamped to [0, 435].
     - Pass threshold: >= 218 (`TO_PASS`).
2. **Senate Conviction Trial Model (`src/engine/evil.ts`)**:
   - `calculateSenateTrialVote(senateSeatDelta: number, heat: number, approval: number, party: 'D' | 'R')`:
     - Opposition party base senators (50 - (party === 'D' ? 0 : 0) + opposition senate delta).
     - Crossover / defection senators driven by critical heat (>85) and public disapproval.
     - Clamped to [0, 100].
     - Conviction threshold: >= 67 (`SENATE_CONVICTION_THRESHOLD`).
3. **Engine Integration (`src/engine/game.ts`)**:
   - In `EvilState`, record:
     - `houseImpeachmentVotes?: number`
     - `senateConvictionVotes?: number`
     - `articlesOfImpeachmentVoted: boolean`
     - `convicted: boolean`
   - If convicted:
     - Instantly forfeit offshore stash (`offshoreStashBn = 0`).
     - Mark `termEnded = true` or terminal game-over condition.
     - Push explanatory log entries into `report.log`.
4. **Unit Tests**:
   - Add unit tests in `src/engine/evil.test.ts` verifying House vote math, Senate supermajority math, stash forfeiture upon conviction, and preservation upon acquittal.
