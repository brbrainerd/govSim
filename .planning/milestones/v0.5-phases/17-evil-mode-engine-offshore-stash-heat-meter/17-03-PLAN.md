# Plan 17-03: Session Evil State, New Game Mode Toggle, and Status Indicators (EVIL-01, EVIL-02)

## Objective
Wire Evil Mode into `Session` (options, reactive stash/heat derivation, legislative friction preview), provide a toggle with civics disclaimers in `NewGame.svelte`, and render offshore stash and heat indicators in `StatusBar.svelte`.

## Scope
1. **Session (`src/app/session.svelte.ts`)**:
   - Add `evilMode?: boolean` to `GameOptions`.
   - Expose derived helpers: `isEvilMode`, `offshoreStashBn`, `heat`, `evilState`.
   - Ensure `preview` passes `this.current.evil?.heat ?? 0` to `resolveBill`.
2. **Status Bar Indicators (`src/ui/StatusBar.svelte`, `src/screens/Game.svelte`)**:
   - Accept `evilMode?: boolean` in `StatusBar.svelte`.
   - When active, render Offshore Stash ($B) and Heat Meter (with threshold warnings) in the resource bar.
   - Show Evil Mode badge in the center area.
   - Pass `evilMode={session.isEvilMode}` from `Game.svelte`.
3. **New Game Mode Selector (`src/screens/NewGame.svelte`)**:
   - Provide accessible mode selection between Standard Mode (Public Servant) and Satirical "Evil Mode" (Kleptocracy).
   - Render contextual satirical disclaimer in the info sidebar explaining personal enrichment vs investigative heat.
   - Pass `{ party, evilMode }` to `onStart`.
4. **Unit Tests (`src/app/session.test.ts`, `src/screens/NewGame.test.ts`)**:
   - Test `evilMode` option preservation and derived indicators in `Session`.
   - Test toggle interactivity and option emission in `NewGame`.
