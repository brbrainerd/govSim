# Plan 17-02: Evil Engine Step Integration, Legislative Friction, Trace & Determinism (EVIL-02, EVIL-03)

## Objective
Wire the Evil Mode engine mechanics into the main simulation loop (`step()` in `src/engine/game.ts` and `resolveBill` in `src/engine/decisions.ts`), register trace sources in `trace.ts` and user-facing copy in `why.ts`, and update deterministic golden replays.

## Scope
1. **Coefficient & Unit Additions**:
   - Register `heatSenateFriction` in `src/engine/coefficients.ts` for Senate legislative opposition votes.
   - Update `calculateHeatPenalties` in `src/engine/evil.ts` to include `senateFrictionVotes`.
2. **Trace & Copy Integration (`src/engine/trace.ts`, `src/content/text/why.ts`)**:
   - Register `'approval:evil'` and `'trust:evil'` in `SOURCES`.
   - Register `'evil:'` prefix in `SOURCE_PREFIXES`.
   - Add plain-language descriptions in `WHY_COPY` and `whyText` with reading grade <= 9.0.
3. **Decisions & Legislative Friction (`src/engine/decisions.ts`)**:
   - Support `evil?: { siphonBn?: number; heatDelta?: number }` in `Decisions`.
   - Update `resolveBill` to accept optional `heat` parameter and apply House/Senate friction hurdles.
4. **Game Loop Integration (`src/engine/game.ts`)**:
   - Add `readonly evil?: EvilState;` to `GameState`.
   - Initialize `evil: defaultEvilState()` in `newGame`.
   - In `step()`: apply natural decay, process evil decisions, enforce institutional thresholds, log milestones, and add trace terms for approval/trust penalties.
5. **Determinism Golden Hash Updates (`src/engine/determinism.test.ts`, `src/engine/replayFixture.ts`)**:
   - Verify deterministic behavior across 1000 randomized property test games (`invariants.property.test.ts`).
   - Recompute and update the 6 golden scenario hashes.
   - Verify zero bare literals via `npm run guard`.
