# Plan 15-01: Sourced Coefficients & Security Index Calculation (SEC-01)

## Objective
Implement pure engine logic for the 0–100 Security Index based on defense readiness posture, alliance strength (foreign assistance), international crisis containment, deterrent sanctions, and domestic public safety.

## Proposed Changes
1. **Coefficients Registration (`src/engine/coefficients.ts`)**:
   - Register sourced coefficients for:
     - `securityBaseline` (50.0 neutral base on 0–100 scale).
     - `securityDefenseSurgeBonus` (+8.0 pts).
     - `securityDefensePeacetimePenalty` (-10.0 pts).
     - `securityForeignAidScale` (0.05 pts per aid point deviation from 100).
     - `securityActiveCrisisPenalty` (-12.0 pts per unresolved geopolitical crisis).
     - `securitySanctionBonus` (+2.5 pts deterrence per active targeted sanction).
     - `securityCrimeScale` (25.0 pts scaling domestic violent crime relative to baseline).
     - `geopoliticalEnergyInflation` (supply disruption cost-push inflation).
     - `geopoliticalShippingInflation` (strait blockade cost-push inflation).
     - `geopoliticalSupplyOutputDrag` (global supply bottleneck GDP drag).
2. **Security Module (`src/engine/security.ts`)**:
   - Create `calculateSecurityIndex(state: GameState): number`.
   - Provide sub-breakdown: `{ defense, alliances, crises, deterrence, domestic, total }`.
   - Ensure strictly arithmetic, no bare literals outside exempt files, clamp to `[0, 100]`.
3. **Unit Tests (`src/engine/security.test.ts`)**:
   - Test neutral starting state equals 50.0.
   - Test defense posture shifts (surge increases, peacetime decreases).
   - Test foreign aid alliance scaling.
   - Test crisis containment penalties.
   - Test bounds clamping `[0, 100]` and determinism.
