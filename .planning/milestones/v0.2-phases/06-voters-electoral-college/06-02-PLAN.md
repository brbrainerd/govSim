<task>
<task_name>2. Build interactive, pattern-encoded USMap.svelte with keyboard navigation</task_name>
<description>
Create `src/ui/art/USMap.svelte`:
- Accepts props: `states: Record<string, StateVoterState>`, `districts: Record<string, StateVoterState>`, `selectedCode: string | null`, `onSelect: (code: string) => void`.
- Embeds SVG `<defs>`:
  - `pattern-hatch`: 45-degree diagonal line pattern using `var(--color-alert)` stroke.
  - `pattern-dots`: Stippled dot pattern using `var(--color-gold)` stroke.
- Renders states with player-relative fills:
  - Player safe/likely/lean: `var(--color-sage)` / `var(--color-sky)`.
  - Opponent safe/likely/lean: `var(--color-brick)` / `var(--color-alert)` with diagonal hatching overlay.
  - Tossup: `var(--color-gold)` with dot stipple overlay.
- District insets / chips for Maine districts (ME-1, ME-2), Nebraska districts (NE-1, NE-2, NE-3), and DC.
- Visual emphasis on selected state (3px mustard gold border) and a star badge on the tipping-point state.
- Keyboard navigation:
  - Each `<path>` and chip has `tabindex="0"`, `role="button"`, and informative `aria-label`.
  - Supports Enter / Space to select, and Arrow keys to navigate between states.
</description>
