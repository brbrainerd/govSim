<context>
OBS-07 establishes automated quality guarantees for accessibility, keyboard navigation, and visual fitting.
The user rule explicitly dictates: "Never ask the user to manually verify UI flows, button visibility, viewport scrolling, tooltips, or keyboard navigation: always audit them yourself with headless Playwright and screenshots across viewports (1376x768, 1280x720) before reporting completion."
This plan codifies those checks as permanent automated tests.
</context>
