<task_files>src/engine/election.ts</task_files>
<action>
Create `src/engine/election.ts`:
- Define `ElectionResult`:
  ```typescript
  export interface StateRollCallItem {
    code: string;
    name: string;
    electoralVotes: number;
    winner: 'player' | 'opponent';
    margin: number;
    isBattleground: boolean;
  }

  export interface ContingentStateVote {
    stateCode: string;
    stateName: string;
    democratSeats: number;
    republicanSeats: number;
    vote: 'D' | 'R' | 'split';
  }

  export interface ContingentElectionResult {
    playerStates: number;
    opponentStates: number;
    splitStates: number;
    winner: 'player' | 'opponent' | 'deadlock';
    rollCall: ContingentStateVote[];
  }

  export interface ElectionOutcome {
    playerEV: number;
    opponentEV: number;
    isTie: boolean;
    winner: 'player' | 'opponent';
    method: 'electoral_college' | 'house_contingent';
    contingentResult?: ContingentElectionResult;
    rollCall: StateRollCallItem[];
    tippingPointState: string;
  }
  ```
- Implement `resolveReelection(gameState: GameState, playerParty: 'D' | 'R'): ElectionOutcome`:
  - Calculate electoral college summary using `calculateElectoralCollege(gameState, playerParty)`.
  - Check if playerEV >= 270 -> winner is 'player'.
  - Check if opponentEV >= 270 -> winner is 'opponent'.
  - If playerEV === 269 and opponentEV === 269:
    - Invoke `resolveContingentElection(playerParty)`.
    - Set method to 'house_contingent'.
- Implement `resolveContingentElection(playerParty: 'D' | 'R'): ContingentElectionResult`:
  - Iterate through all 50 states in `HOUSE_DELEGATIONS` (DC has no entry in `HOUSE_DELEGATIONS`, confirming DC has zero votes per 12th Amendment).
  - For each state: if `democrat > republican` -> vote is 'D'; if `republican > democrat` -> vote is 'R'; otherwise 'split'.
  - Map D and R to player and opponent based on `playerParty`.
  - If playerStates >= 26 -> winner is 'player'; if opponentStates >= 26 -> winner is 'opponent'; else 'deadlock'.
</action>
