<read_first>
- docs/design.md §4, §9
- .planning/REQUIREMENTS.md
</read_first>
<action>
1. Create `PRIVACY.md` in repository root:
   - State clearly and unequivocally:
     - No personal data, tracking cookies, analytics scripts, or telemetry are ever embedded or collected by govSim.
     - Game saves, decisions, and history remain strictly client-side inside the player's browser (`localStorage`).
     - Disclose infrastructure-level logs:
       - Hetzner / Coolify web server proxy access logs (IP address, timestamp, requested static assets, user agent) retained for standard operational reliability.
       - Cloudflare R2 static asset host logs (CDN request counts and asset URLs).
     - Confirm that minors (14+) are protected by the absolute absence of collection (COPPA / UK Children's Code compliant by design).
</action>
