   - `unemployment?: number` (default `4.2`)

   - `evilMode?: boolean` (default `false`)
   - `heat?: number` (default `0`)
   - `stagedCount?: number` (default `0`)

   - `weather`: `'storm'` if `hasCrisis`, `'rain'` if `unemployment >= 5.8 || inflation >= 4.5`, `'sunny'` otherwise. Add `data-weather={weather}` on the root `<svg>`.
   - `presidentMood`: `'scheming'` if `evilMode && heat < 75`, `'panicked'` if `(evilMode && heat >= 75) || (hasCrisis && approval < 42)`, `'stressed'` if `approval < 45 || weather === 'rain'`, `'triumphant'` if `approval >= 58 && !hasCrisis`, else `'confident'`.
   - `advisorMood`: `'panicked'` if `hasCrisis || (evilMode && heat >= 60)`, `'stressed'` if `approval < 48 || stagedCount >= 3`, else `'confident'`.
3. Render upgraded SVG details in `OvalOfficeScene.svelte` (strictly using `var(--...)` tokens):
   - **Windows & Sky**: Sunburst/fluffy clouds in `'sunny'`; angled rain streaks in `'rain'`; jagged gold lightning bolt in `'storm'`; Washington skyline silhouette on the horizon.
   - **Architectural Details**: Wainscoting panels, framed portrait silhouettes on side walls, draped curtains with tie-backs, woven oval rug with stars border (never a presidential seal, per `HANDOFF.md` §8).
   - **Resolute Desk & Props**: Carved oak panels on the desk front, lamp with warm glow cone, steaming coffee mug, stack of folders proportional to `Math.min(4, stagedCount)`, and when `hasCrisis` is true, a flashing red hotline telephone (`data-testid="oval-crisis-phone"`).
   - **Evil Mode Props (`{#if evilMode}`)**: A `"SHRED-O-MATIC"` document shredder beside the desk with paper strips (`data-testid="oval-evil-shredder"`) and an open `"OFFSHORE LEDGER"` folder on the desk.
4. In `src/screens/OvalOffice.svelte`, pass the live reactive props to `<OvalOfficeScene>`:
   - `approval={session.current.approval}`
   - `inflation={session.current.inflation}`
   - `unemployment={session.current.unemployment}`
   - `hasCrisis={Boolean(session.current.activeCrisis || activeGeopoliticalCrisis)}`
   - `evilMode={session.isEvilMode}`
   - `heat={session.current.evil?.heat ?? 0}`
   - `stagedCount={session.stagedActionsSummary.length}`
</action>
