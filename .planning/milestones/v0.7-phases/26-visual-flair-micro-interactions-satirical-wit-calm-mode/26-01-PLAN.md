<task_name>Add Calm Mode state and StatusBar toggle with global CSS motion suppression (JUICE-03)</task_name>
<read_first>
- src/app/session.svelte.ts
- src/ui/StatusBar.svelte
- src/screens/Game.svelte
</read_first>
<action>
1. In `src/app/session.svelte.ts`:
   - Add `calmMode = $state<boolean>(false)` initialized from `localStorage.getItem('govsim_calm_mode') === 'true'` or `window.matchMedia?.('(prefers-reduced-motion: reduce)').matches` (guarded for SSR/Node tests where `window`/`localStorage` may be undefined).
   - Add `toggleCalmMode(): void` that flips `this.calmMode`, writes `'govsim_calm_mode'` to `localStorage`, and sets `document.documentElement.dataset.calm = this.calmMode ? 'true' : 'false'`.
2. In `src/ui/StatusBar.svelte` and `src/screens/Game.svelte`:
   - Pass `calmMode={session.calmMode}` and `onToggleCalm={() => session.toggleCalmMode()}` to `StatusBar.svelte`.
   - Render a compact button in `.when-top` of `StatusBar.svelte`:
     `<button type="button" class="calm-pill" data-testid="calm-mode-toggle" aria-pressed={calmMode} onclick={onToggleCalm} title="Calm mode: disable decorative animations">{calmMode ? 'Calm: ON' : 'Calm'}</button>`
   - In `Game.svelte` global/scoped styles, add `[data-calm='true'] *, [data-calm='true'] *::before, [data-calm='true'] *::after { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; }`.
</action>
