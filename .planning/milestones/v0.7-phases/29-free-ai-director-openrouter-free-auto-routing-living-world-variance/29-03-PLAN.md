<action>
1. Create `src/app/ai-director.ts`:
   - `buildStateDigest(session: Session)`: extracts a compact JSON summary of current turn, season, GDP growth, inflation, unemployment, debt/GDP, approval, clout, active scenario, Evil Mode heat/stash, and recent policy changes.
   - `sanitizeAiText(text: string): string | null`: checks against banned real-world politicians (`trump`, `biden`, `obama`, `vance`, `harris`, `pelosi`, `mcconnell`, `schumer`, `sanders`, `reagan`, `clinton`, `bush`, `powell`, `yellen`) and party names (`democrat`, `republican`, `gop`, `dnc`, `rnc`). Returns `null` if violated or empty.
   - `validateAndClampAiTurnPayload(rawJson: string): AiTurnPayload | null`:
     - Extracts JSON object from markdown fences or raw string.
     - Validates and sanitizes `advisorBubble`, `chyron`, `turnHeadline`, `turnDetail`.
     - If `dynamicCrisis` is present, validates 2–3 options and clamps each option's numeric deltas to `[-C.dynamicCrisisGapCap, C.dynamicCrisisGapCap]`, `[-C.dynamicCrisisInfCap, C.dynamicCrisisInfCap]`, `[-C.dynamicCrisisApprovalCap, C.dynamicCrisisApprovalCap]`, and `[-C.dynamicCrisisTrustCap, C.dynamicCrisisTrustCap]`.
   - `requestAiTurnDirector(session: Session, fetchImpl = fetch): Promise<AiTurnPayload | null>`: calls `generateAiCompletion` and parses via `validateAndClampAiTurnPayload`, returning `null` on any error/timeout so callers fall back cleanly.
2. Create `src/app/ai-director.test.ts` testing:
   - Valid AI JSON payload is parsed and out-of-bounds crisis numbers (e.g. `gapDelta: 99`) are clamped to `C.dynamicCrisisGapCap` (`0.8`).
   - AI output mentioning a banned politician or party name is rejected by `validateAndClampAiTurnPayload` (`null`).
   - Malformed JSON returns `null` without throwing.
</action>
